# Marido de Aluguel & Reformas

Landing page estática para solicitação de orçamentos via WhatsApp **(11) 98770-9179**.

## Executar
Abra `index.html` no navegador ou use `python -m http.server 8000`.

## Publicar no GitHub Pages
No repositório, vá a Settings > Pages, selecione Deploy from a branch, branch `main`, pasta `/ (root)` e salve.

URL prevista: https://mlapuma.github.io/marido-aluguel-site/

## Observações
O formulário não persiste dados; o visitante precisa confirmar o envio no WhatsApp. Confirme região de atendimento, qualificações profissionais e dados comerciais antes de anunciar.
